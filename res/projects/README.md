Project cards are generated by `python3 bin/update_project_cards` from the repository root, using only the Python standard library. Add `--refresh` to fetch current star counts and languages from GitHub. An optional `GITHUB_TOKEN` raises the API rate limit.

Edit `projects.json` to change the selection or descriptions. Each project needs a matching `<repo>.jpg` preview here and a linked `<picture>` in the profile README. The current previews come from the corresponding project READMEs. Both light and dark SVG variants embed their preview, so they require no external image host. The fade-in animation leaves the content visible in viewers that do not animate SVGs.

The GitHub Action refreshes the cards daily at 06:00 UTC, on relevant pushes, or manually through **Actions → Update project cards → Run workflow**. It commits only changed generated files. It needs permission to write repository contents; branch protection rules may prevent the automated push.
